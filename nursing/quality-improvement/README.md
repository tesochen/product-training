## 分享與更新

以本目錄的 index.html 作為固定課程入口，保留 Git 提交紀錄管理版本。院所、日期、時長與受眾可作為課程標籤；有不同 Notebook、問卷或內容的院所專版，另建場次目錄並保留既有連結。

Notebook 及問卷仍使用課程內提供的外部連結，權限由各服務管理。GitHub Pages 公開課程不會自動變更 Notebook 的分享權限。

此為已發布 Sites 課程的 GitHub 發布副本；後續內容修改需要同步更新這裡，尚未建立自動同步。
